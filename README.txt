Annual Poiroux Reunion Bingo PWA

How to use on iPad/iPhone:
1. Host this folder on HTTPS or localhost.
2. Open index.html in Safari.
3. Use Share -> Add to Home Screen.
4. Launch from the Home Screen icon.
5. After the first load, it works offline.

Important:
- Service workers do not run from file:// URLs on iPad or iPhone.
- This version does not include printing.
